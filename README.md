Projeto Imobiliária
Site responsivo para exibição de imóveis com filtros, carrosséis e informações de contato, desenvolvido usando HTML, CSS, Bootstrap e Slick Carousel.

Tecnologias utilizadas
HTML5 & CSS3: Estrutura e estilo da página.

Bootstrap 5: Framework CSS para responsividade e componentes prontos.

Slick Carousel: Biblioteca jQuery para criação dos carrosséis de imóveis.

jQuery: Biblioteca JavaScript para facilitar manipulação do DOM e inicialização do Slick.

Bootstrap Icons: Ícones usados na interface.

Estrutura do projeto
index.html: Página principal.

css/style.css: Arquivo principal de estilos personalizados.

js/script.js: JavaScript para inicialização dos carrosséis e possíveis scripts.

img/: Imagens usadas no projeto.

Arquivos externos importados via CDN: Bootstrap, jQuery, Slick Carousel, Bootstrap Icons.

Funcionalidades principais
Menu de navegação responsivo.

Banner com filtro de imóveis (comprar, alugar, tipo, região, quartos e faixa de preço).

Três carrosséis diferentes para imóveis em destaque.

Sessão de horário de funcionamento com informações da empresa.

Footer com contatos e links institucionais.

Design responsivo, adaptado para dispositivos móveis e desktop.
